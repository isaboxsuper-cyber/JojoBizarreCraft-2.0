# JoJo's Bizarre Mod (NeoForge 1.21.1)

## Compilar no GitHub
Envie esta pasta (com `.github/`) para um repositorio. A aba **Actions** roda "Build mod" e gera o `.jar` em **Artifacts**.

## Controles (Opcoes > Controles > JoJo Mod)
- **Z** invoca/recolhe o Stand
- **ALT (segurar) + scroll** troca a habilidade na Roda; **R** usa a habilidade selecionada
- **V** alterna forma vampiro (precisa da Mascara de Pedra equipada para virar)
- **J** abre o Status (Info + Arvore de habilidades do Stand)

## Comandos de teste (OP)
/jojo stand <id> | hamon | vampire | xp <n> | zeppeli | reset

## Zeppeli
Aparece raramente no mundo (spawn natural). Em mundos ja gerados use o ovo de spawn (aba criativa) ou `/jojo zeppeli`.
